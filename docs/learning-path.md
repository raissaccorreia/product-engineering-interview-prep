# Learning path

This short map carries the technical focus from the study notes into the public practice archive. Personal schedules, job targets, and employer-specific examples remain outside this repository.

## Main areas

- JavaScript and TypeScript fundamentals: values, control flow, collections, typing, async work, errors, and readable functions.
- Data structures and algorithms: select a structure from the operations and constraints in the problem; explain correctness and complexity.
- React and browser behavior: state, derived values, events, effects, refs, rendering, cleanup, and browser APIs.
- Product engineering: APIs, persistence, testing, failure handling, accessibility, performance, and operational trade-offs.
- Technical communication: explain requirements, assumptions, decisions, and limits of evidence in clear English.

## Practice method

For each exercise, select one behavior to implement. Explain the approach first, make the attempt without a reference answer, then inspect the result and debug it. Review the fundamentals and code clarity that affected the attempt. Choose the next behavior only after that review.

Keep the prompt, original attempt, and reference or review in separate files. Mark what was observed, what was reported, and what remains unverified.

The React index describes the current small-increment workflow. The basic exercises and algorithm archive provide short problems for recovering fundamentals between React steps.
