# Evidence inventory

Choose up to three product or engineering examples that can be explained in public. Use [`templates/project-evidence.md`](../../../templates/project-evidence.md) for each one.

Separate verified facts, personal contribution, decisions, and hypotheses. Remove customer, employer, and project details that are confidential. If no metric is available, state that instead of estimating an outcome.

Suggested file names are `case-a.md`, `case-b.md`, and `case-c.md`.
